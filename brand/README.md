# Moka brand kit

**Moka the dino** — a T-rex with tiny arms, holding a big coffee.
*Tiny arms. Strong brew.* ☕

| File | Use |
|---|---|
| `moka-dino.svg` | Primary logo / app icon (rounded espresso tile) — README, npm, GitHub org avatar, Docker Hub |
| `moka-dino-transparent.svg` | The dino without the tile — hero images, stickers, slides |
| `moka-mark.svg` | Simplified head + cup for small sizes (≤ 48 px): favicons, top bars |
| `png/moka-dino-{128…1024}.png` | Raster exports (use 512/1024 for avatars, 180 for apple-touch-icon) |
| `png/moka-mark-{16,32,48}.png` | Favicon rasters |
| `png/social-card.png` | 1280×640 GitHub social preview / Open Graph image |
| `social.html` | Source for the social card (re-render with Playwright) |

## Voice

Confident, warm, a little cheeky. Short sentences. The dino never apologises for its arms.

## Don'ts

- Don't recolour the dino green — it's a coffee dino.
- Don't use the full dino below 48 px; use the mark.
- Don't stretch, add outlines or drop the cup.
