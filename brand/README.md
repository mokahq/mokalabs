# Moka brand kit

**Moka the puppy** — a mocha-patched pup, holding a big coffee.
*Good pup. Strong brew.* ☕

| File | Use |
|---|---|
| `moka-puppy.svg` | Primary logo / app icon (rounded espresso tile) — README, npm, GitHub org avatar, Docker Hub |
| `moka-puppy-transparent.svg` | The puppy without the tile — hero images, stickers, slides |
| `moka-mark.svg` | Just the head, for small sizes (≤ 48 px): favicons, top bars |
| `png/moka-puppy-{128…1024}.png` | Raster exports (use 512/1024 for avatars, 180 for apple-touch-icon) |
| `png/moka-mark-{16,32,48}.png` | Favicon rasters |
| `png/social-card.png` | 1280×640 GitHub social preview / Open Graph image |
| `social.html` | Source for the social card (re-render with Playwright) |

## Voice

Confident, warm, a little cheeky. Short sentences. The pup never spills the coffee.

## Don'ts

- Don't recolour the puppy: the mocha patch and ears are the coffee.
- Don't use the full puppy below 48 px; use the mark.
- Don't stretch, add outlines or drop the cup.
